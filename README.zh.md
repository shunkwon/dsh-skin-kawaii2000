# 雾面玻璃 · dsh 皮肤

[English](./README.md)

给 DeepSeek Harness 网页端的换皮肤：底下一张低饱和的石色到雾蓝桌面，上面铺满
中性白的毛玻璃面板，全站只有一种强调色：石墨。

## 毛玻璃是怎么做出来的

- **玻璃得有个桌面可透。** body 铺一张低饱和的石色到雾蓝渐变加中性暗角，侧栏、
  画布、右栏三块玻璃贴满窗口铺在上面，透上来的只是一点冷暖。3.0 时整扇应用四周
  留 14px 生底、带 20px 圆角浮在桌面上；3.1 起贴边（`--kg-window-inset` /
  `--kg-window-radius` 归零，改回 14px / 20px 就是原来的浮窗），只有从左边缘浮出的
  侧栏还是一块离边 8px、带圆角的玻璃卡片。
- **除了语义色，没有色相。** 灰阶、墨色、发丝线、阴影全是中性的。只有成功、
  警告、错误保留颜色。
- **只有一种强调色。** 石墨（夜间反相成近白），只用在「新会话」「发送」和开关
  开态上，都是实色，不渐变、不发光。
- **全套只有一种阴影语言。** 每个面都是「内侧 1px 亮边 + 内顶 1px 高光 + 外侧
  0.5px 发丝线 + 一团中性淡投影」。
- **圆角只有四档。** 8 / 12 / 16 / 18px，配 `corner-shape: superellipse(1.6)`。
- **系统字体。** 标题和正文都用 SF 和苹方，不加载任何远程字体。
- **对比度对着真实玻璃算。** 墨色 / 次级 / 弱化字是拿渲染后的面色量的：白天
  15:1 / 8:1 / 4.9:1，夜间 11:1 / 7:1 / 4.9:1。
- **该退的时候退。** 系统要求减少透明时，玻璃退回实色；要求减少动效时，全站
  过渡直接关掉。

## 顶栏代替左侧图标栏

布局学 Claude Code：侧栏收起后左边什么都不留，原来那条 56px 的图标栏去掉了，
画布玻璃铺满整扇窗。

- 左上角什么都不放，页头这一行就是顶栏，标题从最左边开始。新会话用 ⌥⌘N 或侧栏
  里的主按钮；触屏上左上角留一颗侧栏开关，标题让出它的位置。
- 图标栏里其余的东西（插件、自动化任务、工作区工具、余额、设置）只在展开的
  侧栏里出现。
- 展开的侧栏顶上不再有品牌行（鲸鱼 + 字标）：石墨色的「新会话」主按钮直接
  顶到最上面，和页头标题行同一条中线。
- 「对话 / 轨迹」页签收进顶栏这一行，页头只剩一行（49px，原来带页签是 79px）：
  标题 → 页签 → 访达 / ⋯ → 右栏开关。页签没有删：轨迹没有快捷键也没有命令，
  视图又按会话记住，删了就回不到对话。
- 页头里除标题以外的东西（智能体团队、预设、对话 / 轨迹、用访达打开、⋯、右栏
  开关）只在指针进到顶栏、键盘聚焦进来或它们的菜单开着时才显示；触屏上一直显示。
  右栏也能用 ⇧⌘B 开。页头窄于 760px
  时「智能体团队」「预设」整个收起，窄于 520px 时页签退回自己那一行，标题始终
  留得出位置。

实现：dsh 的布局本来就有这种摆法，只给 Windows 桌面版的标题栏用。
`lib/topbar.js` 给 `<html>` 打上 `data-windows-titlebar`，收起列宽就变成 0、两颗
按钮固定到左上角。它同时把标题栏高度设成 `0px` 并打上 `data-kg-topbar`，具体
落位由 `skin.css` 的 6b 节负责。那一节只认 `data-kg-topbar`，真的 Windows / macOS
桌面版不受影响。没用 `data-platform="darwin"`：快捷键包会把它当成 Electron 运行
环境。哪天 dsh 升级后图标栏又回来了，先查 `dsh-client-ui-layout` 的
`collapsedWidth` 和 `dsh-client-ui-sidebar` 里的 `[data-windows-titlebar]` 规则。

## 从左边缘呼出侧栏

用鼠标时没有侧栏开关按钮，侧栏从窗口左边缘拉出来：

- **浮出**：指针碰到窗口最左边那 8px 停一下（约 0.12 秒），侧栏就作为一块浮起的
  玻璃卡片从左边滑出，盖在正文上面，正文原地不动。指针靠近左边缘时，窗口左边会亮出
  一道竖短条，提示这里能拉出东西。按着鼠标（比如从左边开始框选文字）时不会浮出。
- **收回**：指针离开侧栏（右缘再宽出 24px 都算在上面）约 0.3 秒就滑回去，滑走途中
  指针回到侧栏上，它就原路滑回来。从侧栏里打开的菜单开着、在侧栏搜索框里打字、
  按着鼠标在拖时都不收。
- **钉住**：浮出时按 ⌥⌘B，卡片贴回窗口左边，正文让开、侧栏常驻，就是以前展开的
  样子。钉住后再按 ⌥⌘B，侧栏滑走、正文铺满。快捷键读的是应用自己的绑定，改过也认。
- 触屏没有悬停，那里左上角照旧有侧栏开关，点它展开 / 收起。

动起来的只有侧栏自己：正文不跟着动画，要么原地不动，要么等侧栏停下来才一次让开或
铺满。浮出、收回时正文从头到尾不重排。

实现在 `lib/sidebar-peek.js`，状态写在 `<html data-kg-side>` 上，几个词用空格隔开：
`overlay`（画布横跨侧栏那一列，盒子不变）、`card`（浮起的卡片样式）、`hidden` /
`leaving`（侧栏摆到 / 滑到窗口左边外面）。`skin.css` 只认这几个词，动画只有侧栏的
`transform`。布局自己的列宽过渡关掉了，展开、收起时列宽一步到位。切换侧栏时按的是
应用自己的快捷键（比点开关少一半渲染），认不出来才点开关。

为什么这样做：长对话（七千多个节点）里，画布宽度变一次，WebKit（DeepSeek.app 用的就是
它）要重排加重画 60~90ms。以前侧栏列宽和画布的负 margin 一起过渡，等于每一帧都付一次，
浮出时一次就掉六七帧；现在这一下只在侧栏不动的时候付一次，滑动本身不掉帧。

**维护提示**：侧栏一展开、收起，布局就改几个会继承的 CSS 变量（`--dsh-windows-sidebar-width`
写在 frame 上，`--dsh-windows-menu-start` 由 ui-sidebar 写在根上）。WebKit 里祖先上的
继承变量一变，底下每个节点都要重算样式，长对话每次 34ms 起。`skin.css` 把前者在画布和
侧栏两列上钉成常量、把后者钉死，`--dsh-frame-leading-clearance` 三种状态都写同一个值
（DeepSeek.app 里标题要让开红绿灯，那个偏移只写在页头上）。
以后再加会随侧栏状态变的变量，别直接写在 frame 或根上。

## 搜索结果直接跳到关键词

侧栏搜索（⌥⌘K）能搜到对话正文时，点一条结果会打开会话、滚到关键词所在的地方，
那一处用深一点的黄色标出来，这个会话里其它出现处用浅黄色；结果列表里的标题和摘录
也把关键词标出来。应用自己只打开会话、停在底部，这一段是皮肤补的。

- 关键词在更早的历史里时，会自动点「加载更早」往前翻（最多 10 页）再找。
- 出现好几处时，按结果摘录里关键词前后的字挑最像的那处（摘录就是搜索后端选出的
  最佳匹配）。
- 跳过去后 3 秒内应用若又把视图拉回底部，会滚回来；你自己一滚动、点击或按键就不再管。
- 对话区右上角浮出命中条「关键词 2 / 5 ↑ ↓ ×」：一共几处、现在是第几处一眼就知道。
  ↑ ↓ 或 ⇧⌘G / ⌘G 在各处之间跳，× 关掉并清高亮。只数页面上已有的内容（已加载的轮次，
  含折叠起来的步骤）；还有更早的历史没加载时写成「5+」，翻到头也没找到写「无匹配」。
- 切到别的会话，命中条收起、高亮清掉。
- 关键词在一轮里被折叠起来的步骤里（「已完成，用时…」下面那些）时，先把它展开再跳，
  和浏览器自带的页内查找一样。根本没渲染出来的内容（比如没点开的工具输出）找不到，
  这种情况只打开会话、不跳。

实现在 `lib/search-jump.js`，高亮用 CSS Custom Highlight API（`CSS.highlights`，
不改 DOM），颜色是 `skin.css` 里的 `--kg-find` / `--kg-find-current`。

## 文件面板：常用文件夹置顶

工作区是家目录时，⌥⌘P 打开就是两百多项，最前面全是 `__pycache__` 和点开头的隐藏目录。
皮肤把每一层里常用的文件夹排到最前（最多 8 个），下面一条细线隔开：

- **默认**：家目录那一层的 projects、Documents、Desktop、Downloads。
- **自动**：同一层里展开过 3 次以上的文件夹（每层取前 3 个）。为了不让刚点的那行从
  指针下跳走，排序在这一层下次显示时生效。
- **手动**：指针停在文件夹行上，右边出一个图钉，点一下钉住 / 取消；钉住的行平时留一个淡图钉。
  取消过的（包括默认那几个）不再自动置顶。
- **记住展开**：重新打开面板、刷新页面或换回这个会话时，上次展开着的文件夹按层自动点开
  （最多 12 个，只限当前工作区）。收起一个文件夹会连它底下的一起忘掉。

- **按时间排序**：面板顶上「时间 | 名称」开关，默认时间——整层文件夹和文件混在一起，按修改时间从新到旧；
  「名称」退回原来的文件夹在前、按名称。几千项的目录（如 Downloads）只列 2000 项时，留下的是最新的那些。
  排序要 dsh 的本地补丁 `~/.dsh/patches/files-sort-by-time.mjs`（让列目录带上修改时间、面板按选择排），
  升级 dsh 后重跑它并重启 dsh；补丁不在时开关不显示，面板按名称排。

实现在 `lib/files-pin.js`：只给置顶的行写 CSS `order`，不搬应用的节点；记录存在浏览器的
localStorage（键 `kg-files-pin:v1`），DeepSeek.app 和浏览器各记各的。

## 在 DeepSeek.app 里：顶栏就是标题栏

DeepSeek.app（Dock 上那个 WKWebView 外壳，源码在 `~/Library/Application Support/DeepSeekWebApp`）
不再单独占一行标题栏。和 Claude Code 一样，红绿灯就在页面顶栏那一行的最左边，
这一行的空白处可以拖动窗口：

- **收起时**：会话标题紧接在红绿灯后面，这一行和红绿灯同一条中线。
- **侧栏展开时（钉住或浮出）**：侧栏顶上空出这一行给红绿灯，「新会话」排在它下面。
- 双击这一行的空白处，按系统设置（桌面与程序坞）执行：最小化、缩放或不动。
- 全屏时红绿灯藏起来，布局退回浏览器里的样子。

app 和皮肤在 `<html>` 上约定好几样东西，由 app 在页面一开始加载时写上：

- `data-native-titlebar`：红绿灯正显示着，全屏时拿掉。
- `--native-titlebar-height`：这一行的高度，等于红绿灯中线的两倍（macOS 26 是 52px）。
- `--native-controls-end`：缩放按钮的右缘（79px）。

WebKit 不认 `app-region`，所以拖窗口由 app 来做。页面只报告指针是不是在这一行的空白处：
底下没有可点的东西，也没有菜单或弹窗开着。app 收到后，在这里按下鼠标就直接当作拖窗口，
这一下页面根本收不到。

有这个属性时，`skin.css`（6b 节末尾）做这几件事：

- 让会话页头正好就是这一行。
- 收起或浮出时，标题让到红绿灯后面。
- 侧栏内容从这一行下面开始。
- 插件页、自动化页的大标题挪到这一行下面，和 dsh 官方 mac 版一样。
- 弹窗不碰这一行。
- 全屏右栏的页签条让到红绿灯后面。

`lib/sidebar-peek.js` 在这一行里不算碰到左边缘，伸手去点红绿灯时侧栏不会浮出来。
浏览器里没有这个属性，以上都不生效。不装这个皮肤的话，红绿灯会压住会话标题。

## 安装

三步搞定：

**1.** `~/.dsh/profiles/web/package.json` 的 `dependencies` 里加一行：

```json
"dsh-skin-kawaii2000": "github:shunkwon/dsh-skin-kawaii2000"
```

**2.** `~/.dsh/profiles/web/cordis.patch.yml` 里加一段：

```yaml
- insert:
    - id: skin-kawaii2000
      name: dsh-skin-kawaii2000
```

**3.** 装包、重启 dsh：

```bash
cd ~/.dsh/profiles/web
pnpm install
```

装好后打开 http://127.0.0.1:3080 就能看到。

> 包名仍是 `dsh-skin-kawaii2000`，loader 里那行也不用改。外观改过两次：2.0 把
> 2000 年代的斜角换成糖果毛玻璃，3.0 去掉了糖果色。id 一直沿用，现有 profile
> 不用改 patch 就能升级。v1 那一版留在 git 的 `v1-kawaii2000` 标签上，v2 糖果
> 毛玻璃是提交 `d48950b`。

### 不想用了？

给 patch 里那行加 `disabled: true` 再重启，或者把上面加的两处都删掉。

## 维护提示：`[class*=…]` 请只挂一层

皮肤靠 `[class*="_xxx"]` 匹配组件内部类名（类名形如 `<hash>_<local>`，后缀稳定）。
substring 匹配很容易命中嵌套子节点 —— 比如 `[class*="_card"]` 会同时命中
`li.card` 和 `cardHead` / `cardMain` / `cardDesc` / `cardIcon`，给每一层都套上
圆角描边，看起来像一条白条盖住了文字。

改完样式后，在浏览器控制台粘 [tools/audit-nesting.js](./tools/audit-nesting.js)
跑一遍（插件页、设置→内置插件、对话、首屏各跑一次），输出为空才算干净。
跑的时候让一个提示气泡开着：Tooltip 的类名也带 `_bubble`，曾经被聊天气泡那条
规则一起刷成透明底，只有气泡在屏幕上时才查得出来。

## 维护提示：玻璃面会把提示气泡带偏

侧栏、画布、右栏都有 `backdrop-filter`，它让元素成为 `position: fixed` 子元素的
包含块。dsh 的 Tooltip 是 fixed 定位、按窗口坐标摆的，于是会偏出一个面板原点
（画布在侧栏展开时是 294px，提示直接出了窗口）。[lib/tooltip-fix.js](./lib/tooltip-fix.js)
在气泡出现或移动时量出包含块原点、用 `translate` 抵回去，并把贴边的气泡收回面板
以内。给新的面板加玻璃时不用另外处理；要按面板坐标亲手摆某个提示（像展开时开关
那个），写 `translate: none !important`。菜单用的是 CSS 锚点定位，不受影响。

## 维护提示：static 色板别反相

dsh 的令牌分两层：`--dsw-static-*` 是绝对色（主题的夜间表几乎不动它，`bluish-00`
始终是白、`bluish-1000` 始终是近黑），`--dsw-alias-*` 才跟着主题翻。组件会直接用
static —— 提示气泡的字和快捷键键帽就是 `var(--dsw-static-neutral-bluish-00)`，
底色却是 alias。所以夜间表里 static 只能「调亮当前景色用」，不能把白那一端翻成深色，
否则就是黑底黑字。

改完颜色，白天夜间各开一次，把提示、菜单打开，在控制台粘
[tools/audit-contrast.js](./tools/audit-contrast.js)：它按元素实际落到的底色算
对比度，列出低于 3 的字和图标，夜间再列出偏白的面。
